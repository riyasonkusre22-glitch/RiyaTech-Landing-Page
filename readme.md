# RiyaTech – Responsive Landing Page

## Internship Task 1: Web Development
### Project Overview
RiyaTech is a modern and responsive landing page developed using HTML5 and CSS3.

### Objective
To create an attractive landing page that works on desktop, tablet, and mobile devices.

### Technologies Used
- HTML5
- CSS3
- Visual Studio Code
- Google Chrome

### Features
- Responsive navigation bar
- Hero section
- About section
- Skills section
- Projects section
- Contact section
- Footer with social links
- CSS animations and hover effects

### Concepts Learned

- HTML structure
- CSS styling
- Flexbox
- CSS Grid
- Media queries
- Responsive web design
